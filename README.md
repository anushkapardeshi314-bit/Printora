# Printora Python / Streamlit app

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

For camera scanning on a phone, open the deployed app over HTTPS and allow camera access. The camera feature may not work on an insecure HTTP page.

## What this starter includes
- Camera capture using Streamlit
- Upload multiple images and PDF documents
- PDF page rendering
- Portrait / landscape, A4 / A3 / Letter / Legal
- Colour or grayscale output
- Copies, pages-per-sheet layouts, margins and page numbers
- Brightness, contrast and rotation
- Downloadable print-ready PDF

## Printing and printer connection
This app creates a print-ready PDF. It does not silently connect to or control every printer. Open the downloaded PDF and use the device's print dialog to select a compatible Wi-Fi, USB, or network printer. Duplex, tray, ink and quality controls depend on the printer and driver.

The app is free to run, but paper, ink/toner and printer access may still cost money.
